# lord-software

The first version of the `pahiy.site` Discord bot. It sets its presence to
"Watching pahiy.site" and shares a link to the site through the `/site` slash
command.

> **Archived.** This repository contains the same code as `pahiy.site-bot` and
> is its predecessor. It is no longer maintained.

## Built with

Node.js · discord.js v14 · dotenv
